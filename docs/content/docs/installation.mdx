# Installation & Setup

## 📦 Package Installation

Install `agent-sdk` alongside your preferred schema validation and provider libraries using your package manager of choice:

```bash
# Using pnpm (recommended)
pnpm add agent-sdk zod

# Using npm
npm install agent-sdk zod

# Using yarn
yarn add agent-sdk zod
```

---

## ⚙️ TypeScript Configuration

Agent SDK is built with modern ES Modules and strict TypeScript support. Ensure your `tsconfig.json` includes the following recommended compiler settings:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

---

## 🔑 Environment Variables Setup

Store your LLM provider credentials in environment variables or a `.env` file at the root of your project:

```bash
# Provider API Keys
OPENAI_API_KEY="sk-proj-..."
ANTHROPIC_API_KEY="sk-ant-api03-..."
GEMINI_API_KEY="AIzaSy..."

# Optional SDK Environment Flags
AGENT_SDK_DEBUG=true
AGENT_SDK_LOG_LEVEL=info
```

Load environment variables automatically using `dotenv`:

```typescript
import dotenv from 'dotenv';
dotenv.config();
```
