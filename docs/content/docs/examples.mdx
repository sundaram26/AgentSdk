# Executable Examples

The [`examples/`](https://github.com/sundaram26/AgentSdk/tree/main/examples) workspace directory contains 4 standalone, runnable example applications:

| Example | Feature Demonstrated | Run Command |
|---|---|---|
| **[basic-agent](https://github.com/sundaram26/AgentSdk/tree/main/examples/basic-agent)** | Single tool registration, debug logger, trace metrics | `pnpm --filter basic-agent start` |
| **[multi-agent-handoff](https://github.com/sundaram26/AgentSdk/tree/main/examples/multi-agent-handoff)** | Sub-agent routing and context preservation | `pnpm --filter multi-agent-handoff start` |
| **[structured-output](https://github.com/sundaram26/AgentSdk/tree/main/examples/structured-output)** | Zod output validation and automated self-repair | `pnpm --filter structured-output start` |
| **[streaming-chat](https://github.com/sundaram26/AgentSdk/tree/main/examples/streaming-chat)** | Async event stream iteration via `agent.stream()` | `pnpm --filter streaming-chat start` |
