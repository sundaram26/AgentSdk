# Welcome to Agent SDK

**Agent SDK** is an enterprise-ready, TypeScript-native framework for constructing resilient, type-safe, autonomous AI agents. Built around the **Ports & Adapters (Hexagonal)** architectural pattern and driven by a **Deterministic Finite State Machine (FSM)** runtime, Agent SDK delivers unmatched control, observability, and safety for production LLM workloads.

---

## 🎯 Core Capabilities

### 1. Hexagonal Ports & Adapters Architecture
Completely decouples core agent logic from underlying LLM providers. Easily swap between **OpenAI**, **Anthropic**, **Gemini**, or custom self-hosted endpoints without changing business logic.

### 2. Finite State Machine (FSM) Runtime
Executes runs through 6 explicit runtime states (`PLANNING`, `EXECUTING`, `VERIFYING`, `DONE`, `AWAITING_APPROVAL`, `FAILED`). Guarantees strict loop limits, state transition logging, and predictable failure handling.

### 3. Safety Guardrails & Human-in-the-Loop Approval
Intercept inputs, tool calls, and outputs with layered validation pipelines:
- **Prompt Injection Defense**: Regex and semantic pattern matching.
- **Tool Boundaries**: Whitelisting, blacklisting, and human approval gates (`AWAITING_APPROVAL`).
- **PII Redaction**: Automatic masking of sensitive emails, phone numbers, SSNs, and credit cards.

### 4. Multi-Agent Context-Preserving Handoffs
Seamlessly delegate complex tasks to specialist sub-agents while preserving complete conversation state and history.

### 5. Structured Output & Self-Repair Engine
Bind Zod schemas to agent responses. If an LLM generates invalid JSON, Agent SDK automatically constructs field-level correction prompts and retries up to a configured threshold.

### 6. Multi-Tier Memory Engine
Store persistent user facts and semantic episodic session history. Automatically inject relevant memories into system prompts.
