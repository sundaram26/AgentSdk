# Multi-Provider Fallback Chain

Ensure 99.99% availability by chaining multiple LLM provider adapters using `FallbackChain`. If the primary provider experiences rate limits, timeouts, or API outages, execution seamlessly fails over to secondary providers.

---

## 💻 Code Example

```typescript
import { createAgent, FallbackChain, OpenAIAdapter, AnthropicAdapter, GeminiAdapter } from 'agent-sdk';

const resilientLlm = new FallbackChain({
  adapters: [
    new OpenAIAdapter({ apiKey: process.env.OPENAI_API_KEY }),
    new AnthropicAdapter({ apiKey: process.env.ANTHROPIC_API_KEY }),
    new GeminiAdapter({ apiKey: process.env.GEMINI_API_KEY }),
  ],
});

const agent = createAgent()
  .llm(resilientLlm)
  .build();

const result = await agent.run('Execute mission critical task');
```
