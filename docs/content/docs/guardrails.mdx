# Guardrails & Approval Gate

Agent SDK provides an enterprise-grade safety engine operating across three stages: **Input**, **Tool**, and **Output**.

---

## 🛡️ Built-in Guardrail Rules

### 1. `PromptInjectionRule` (Input Stage)
Scans incoming user prompts for known prompt injection patterns, system overrides, and jailbreaks.

```typescript
import { PromptInjectionRule } from 'agent-sdk';

agentBuilder.inputGuardrail(new PromptInjectionRule());
```

### 2. `ToolBoundaryRule` (Tool Stage)
Enforces tool execution policies:
- `restrictedTools`: Completely blocks blacklisted tools.
- `requireApprovalTools`: Pauses run in `AWAITING_APPROVAL` status until a human approves.

```typescript
import { ToolBoundaryRule } from 'agent-sdk';

agentBuilder.toolGuardrail(
  new ToolBoundaryRule({
    restrictedTools: ['rm -rf', 'drop_table'],
    requireApprovalTools: ['delete_database', 'transfer_funds'],
  })
);
```

### 3. `PIIRedactionRule` (Output Stage)
Automatically detects and redacts sensitive email addresses, phone numbers, SSNs, and credit cards.

```typescript
import { PIIRedactionRule } from 'agent-sdk';

agentBuilder.outputGuardrail(new PIIRedactionRule());
```

---

## 🙋 Human-in-the-Loop (`ApprovalGate`)

When a tool requiring human confirmation is invoked, the run pauses with status `'AWAITING_APPROVAL'`:

```typescript
// 1. Initial run triggers approval request
const run = await agent.run('Delete production database users');

if (run.status === 'AWAITING_APPROVAL') {
  const approvalReq = run.pendingApproval;
  console.log('Approval Request:', approvalReq.toolName, approvalReq.arguments);

  // 2. Human reviewer resumes run with decision (true = approve, false = reject)
  const resumeResult = await agent.resume(approvalReq.id, true);
  console.log('Resumed Result:', resumeResult.output);
}
```
