## Reproducing Benchmark Results

Execute the automated benchmark harness locally or in CI/CD using the repository scripts:

```bash
# 1. Clone repository and install dependencies
git clone https://github.com/sundaram26/AgentSdk.git
cd AgentSdk
pnpm install

# 2. Configure target evaluation provider credentials
export OPENAI_API_KEY="sk-proj-..."
export ANTHROPIC_API_KEY="sk-ant-..."

# 3. Run the automated benchmark harness
pnpm benchmark
```

Results will be exported to `benchmarks/results.json` and formatted into summary tables automatically.
