# Security Policy

## Supported Versions

Currently, only the latest major version of the Agent SDK is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for the Agent SDK, especially given its capabilities to execute tools and interact with LLMs. 

If you discover a security vulnerability within this project, please do NOT create a public issue. 
Instead, please privately report it by emailing the project maintainers or using the GitHub Security Advisory "Report a Vulnerability" feature if available on the repository.

Please include the following information in your report:
- The version of the SDK you are using.
- A detailed description of the vulnerability.
- Steps to reproduce the vulnerability (proof of concept).
- Potential impact and, if possible, any suggested mitigation.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. Once the issue has been resolved, we will publish a security advisory and credit you for the discovery.
